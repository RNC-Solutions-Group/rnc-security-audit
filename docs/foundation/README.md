# Historical foundation — original audit-orchestration concept

The repository began as an orchestrator for existing scanners. Its sketches and original proof plan remain useful, but the current product direction now adds a **first-party RNC Scanner detection engine**. This folder holds byte-for-byte snapshots of that earlier documentation, collected under [orchestration-v0](orchestration-v0/README.md).

These documents are **historical references, not current instructions or implemented capabilities**. Some relative links inside the original files point to their former locations; the [archive index](orchestration-v0/README.md) supplies working links to all of them.

The active source of truth is the [architecture contract](../architecture/README.md) and [current roadmap](../roadmap.md). We retain valuable ideas—multi-scanner preflight, Docker/native backends, target confirmation, no-read exclusions and raw/sanitized reporting—for planned orchestration integration.
