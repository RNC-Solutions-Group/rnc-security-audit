# Pre-scoring-fix report archive

These tracked reports predate the scoring-integrity remediation and are **not**
current baselines. They are preserved twice:

- original files at their historical paths, so existing documentation links and
  immutable report hashes continue to resolve;
- an offline archive at [`pre-scoring-fix-reports.zip`](pre-scoring-fix-reports.zip).

`MANIFEST.json` indexes every archived file and includes SHA-256 values for the
individual files and the zip archive. The originals were not moved, rewritten or
deleted.

The fresh current-scoring baseline is under
[`../../baselines-20261115/`](../../baselines-20261115/). Do not compare a
pre-fix report against a current report without labeling the scoring revision.
